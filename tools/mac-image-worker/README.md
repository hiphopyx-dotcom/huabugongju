# 剧爆棚图片工作端

把网站图片任务交给现有 Mac 执行，结果回传到提交任务的账号和项目。Mac 必须保持开机、联网，本应用必须保持运行。

## 使用

1. 在网站管理员页面下载“图片工作端连接文件”。该文件含网站工作端凭据，请勿分享。
2. 双击“剧爆棚图片工作端.app”，点击“导入网站连接文件”，选择下载的 JSON。
3. 在本机密钥框粘贴模型 API 密钥，点击“保存到本机钥匙串”。不要把密钥发到聊天或网站成员页面。
4. 点击“启动工作端”。连接检查只读取认证接口的 HTTP 状态，不请求生成图片、不读取账户信息。检查通过后领取网站任务。
5. 使用完点击“停止”。关闭窗口后应用仍会运行；退出应用会先停止子进程并保留任务回执。

网站中的“估算 token”是站内额度。模型服务仍按其实际计费规则收取费用；本工具不从图片响应伪造真实 token 用量。

“测试视频（3秒）”是单独的管理员诊断。它需要用户在本机确认一次付费预算，只验证模型账号能否生成视频；目前不会把视频自动回传网站。见 `tools/mac-video-test/README.md`。

## 构建和测试

使用系统 Swift、Cocoa、Security，以及本机已有的 Node.js 24。无需下载依赖。界面检查 `/usr/local/bin/node` 和 `/opt/homebrew/bin/node`。

```sh
node --test tools/mac-image-worker/worker.test.mjs
sh tools/mac-image-worker/build-app.sh
```

构建默认写入此目录的 `build/剧爆棚图片工作端.app`。指定其他目标路径可作为脚本第一个参数；已有目标不会覆盖。构建产物只做本机临时签名，未公证。

## 连接和回执

连接文件固定格式为 `jbp-mac-image-worker-v1`，工作端标识 `primary`；仅接受明确列入代码的腾讯云站点和原 Vercel 站点。网站凭据仅发送到网站接口；模型密钥只通过子进程环境发送到固定模型 API，不写磁盘、命令行参数或日志。密钥保存在本机钥匙串。

本机数据位于 `~/Library/Application Support/JubaopengImageWorker/`。目录权限为 0700，连接文件和回执为 0600。回执只记录任务编号、租约、执行状态和待回传结果，可能临时保存生成图片，不记录模型密钥或账号资料。网站确认接收后，本机回执删除图片和租约，只保留确认状态。

每个任务调用模型最多一次。调用前落盘意图，完成后先落盘结果，再向网站回传。启动时只重传保存结果；只有意图而没有结果的任务回传“待核对”，不会再次出图。网络错误、超时、异常响应或服务端错误均按结果不确定处理。

网站完成接口最多重传三次同一结果。凭据撤销会停止工作端；租约过期会把结果保存在 `review` 回执，交管理员核对。不会凭旧租约重新生成。`review` 回执不会在后续启动时自动重传或重跑，请保留供管理员处理。

进程锁防止同一目录同时运行多个工作端。若异常断电后提示锁文件需检查，先确认活动监视器里没有仍在运行的此图片工作端 Node 子进程，再移除该目录里的 `worker.lock`。不要删除 `receipts/`；删除回执会失去防止重复生成的记录。

可选命令行运行：`XAI_API_KEY` 由本机安全环境提供，再运行 `node worker.mjs /绝对路径/connection.json`；不要把密钥作为命令行文字或参数输入。桌面应用优先使用钥匙串。

剧爆棚 · Mac 文字工作端 V3

已完成：本工具可以领取工作台的文字任务，使用本机已授权的 Grok Build 账户生成文字，再把结果返回提交任务的手机号账户。
范围：仅文字。图片、视频生成尚未验证，也没有接入本通道。

你的 hiphopyx@gmail.com 在 V2 完成的授权可以继续使用，不需要重复登录。

连接步骤
1. 在 https://jubaopeng-canvas.vercel.app/ 用管理员手机号登录，打开“管理员入口”。
2. 在“Grok账户池”找到对应账户。没有时先登记邮箱或标识。
   点击该账户的“下载 Mac 连接配置”，得到 JBP-Mac-Connection-…json。
   连接配置只能领取此账户的文字任务。再次下载会使旧配置失效；它不含 Grok 密码，但本身是连接凭据，请勿发到聊天、GitHub或群里。
3. 解压V3，双击 Start.command，选6导入连接配置。
   将下载的 JSON 文件拖入终端后回车；本机账户标识填写 hiphopyx@gmail.com。
   这个标识必须与V2授权时输入的完全一致。其他账号填写它各自在本机授权时的标识。
4. 选7启动文字工作端，保持终端运行和Mac联网、唤醒。按Ctrl+C停止，登录记录会保留。
5. 网站顶部打开“文字生成”。管理员可选择测试账户；成员自动使用后台分配的账户。
   输入文字要求后提交，在“我的最近任务”查看排队、生成、完成或错误状态。只显示本人提交的结果。
6. 用管理员“已有账户”里的“保存匹配”，即可给不同手机号改绑对应账户。
   一个Grok账户可对应多个手机号，生成端逐条处理。改绑后成员需要重新登录。

其他账户
仍可在菜单1浏览器授权、菜单2设备码授权、菜单3验证文字，然后为每个账户下载并导入对应连接配置。
本机授权与网站账户名称可以不同，但管理员应在官方登录页面亲自确认实际身份，避免选错Grok账户。
不同账户有独立的GROK_HOME，不覆盖原先的 ~/.grok。
网站、Mac和第三方模型的连接是否实际成功，以线上测试任务的真实返回为准。

依赖及限制
需要Node.js22或更新版和npm；缺少时从 https://nodejs.org/ 安装官方macOS版本。
首次授权会询问是否安装官方 @xai-official/grok@1.0.60 到本机独立目录，无需sudo。
本工具仅在本机读取 auth.json 中的邮箱和用户标识，用于核对账户；不输出或上传令牌。Grok 登录凭据仍由官方 CLI 管理。
连接只允许本站正式域名，不监听本机或公网端口。不会设置开机启动。
后台为每个生成账户设置执行锁；单次本机执行最多75秒。超时不会自动重新生成，避免重复使用额度。
网络失败可以重试回传，但不会重新执行同一已领取任务。Mac断线或休眠时，网站会显示离线或任务超时。
新建、重置成员密码及改绑会使成员旧会话失效。成员停用或分配改变时，旧任务不能继续排队；正在执行的失效任务不会回传给成员。
任务执行拒绝所有工具调用、子代理和网页搜索，不将成员输入当成Shell命令。
每个成员最多3个待完成任务，每个生成账户最多50个待完成任务。文字要求最多8000字，返回最多64KB。
本机数据：~/Library/Application Support/JubaopengGrokAuth/
诊断报告 JBP_Auth_Report_…json 只含账户标识、历史状态和时间，不含密码、令牌或模型原始回复，可以发送给助手排查。

验证说明
代码测试涵盖接口执行闭环、权限隔离、改绑失效、连接撤销、并发领取、超时、结果限制，以及本机参数传递。
集成测试使用受控模拟模型，不代表已经在你的Mac上完成“网站→真实Grok→网站”验证。
真实Grok文字能力已由你在V2实测；本次仍需按上述步骤启动V3后，提交一次网站文字任务完成最终验证。

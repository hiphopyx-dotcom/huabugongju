# 剧爆棚 · AI影像创作工作台 V3

Sites/Vinext + D1 + R2 云端工作台；原有精简版和正式版、本地 IndexedDB 项目保持兼容。模型 API 仍未接入。

## 已实现

- 多项目、剧本与分集、分镜拆解及镜头表、节点画布与上游数据传递。
- 素材上传、角色参考锁定、图片裁剪调色、候选图对比、视频取帧。
- 时间线、视频入点和切分、音轨与淡入淡出、动态图片预演、字幕样式与 SRT/VTT。
- 浏览器 Canvas/Web Audio/MediaRecorder 合成 WebM；麦克风录制配音、系统语音朗读（不产生音频文件）。
- ChatGPT 网站身份，按账号隔离的云端项目；媒体单独存入 R2，项目元数据和版本索引存入 D1。
- 云保存、跨设备下载恢复、旧本地项目自动备份、历史版本恢复为副本。
- 服务端 owner/editor/viewer 权限、项目成员管理、评论审阅和解决状态。
- 乐观并发控制：旧 revision 保存返回 409，不会覆盖另一设备的新版本。
- 未配置生成服务时任务等待，不伪造完成结果。

## 云端流程

1. 原设备打开项目，点击“云保存”。
2. 在另一设备使用同一 ChatGPT 账号打开网站。
3. 进入云端项目，刷新列表，点击下载打开。
4. 云保存是明确操作；本地编辑依旧自动保存。多人协作通过保存、下载和评论审阅，尚无实时多人光标。
5. 添加成员要求该账号已通过网站访问范围设置获准访问并至少打开云端页一次。应用内成员操作不发送邮件，不修改网站访问范围。

## 服务端

- `app/api/cloud/[...path]/route.ts` 接收请求并调用 Sites 身份助手。
- `lib/cloud-service.mjs` 实现身份校验、权限控制、同源写入、项目和媒体服务。
- `db/schema.ts` / `drizzle/` 为云端表和迁移。
- 迁移由 Sites 发布应用；不在请求处理里建表。
- `public/studio/cloud.mjs` 客户端同步；`app.mjs` 为工作台逻辑。

## 验证

`node --test tests/*.test.mjs` 验证数据规则、应用流程、云端保存恢复、版本冲突、成员权限和素材隔离。
`node_modules/.bin/tsc --noEmit` 验证 TypeScript。
用 Sites `build-site.mjs` 构建并发布。

环境未提供 Sites 支持的 control-browser，未启动浏览器预览。麦克风授权、视频解码和 WebM 编码必须在目标浏览器实际验收，测试替身不是浏览器验收。

## 当前边界

- 未接入 AI 剧本、图像、视频或合成配音的生成模型 API。
- 未实现实时多人共同编辑、多人光标、计费充值、服务端 MP4 渲染、专业调色与完整 LibTV 功能等价。
- 媒体至多50MB，项目导入至多250MB，云端结构至多4MB；本地视频导出10分钟以内，保持前台。
- 角色锁定固定参考图与设定，实际生成一致性取决于模型能力。

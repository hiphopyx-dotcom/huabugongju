# Seedance 2.0 Skill OS 研究存档

上游：https://github.com/Emily2040/seedance-2.0（MIT，v6.7.0）

Seedance 2.0 Skill OS 是一套面向 Seedance / 即梦类视频模型的 **Agent 技能包**：把模糊想法编译成有导演意图的提示词。它本身不生成视频、不计费；生成仍走你自己的平台。

## 我们怎么存

- **不**把整仓或安装器拷进产品依赖，也不在工作台里执行其脚本。
- 文档记下可复用的片场规矩；视频页提供原创「导演配方」提示词骨架（`public/studio/directing-recipes.mjs`）。
- 做法与 `docs/video-prompt-templates.md` 一致：参考外部项目的产品定位，落地自有提示词库。

## 可复用的规矩（摘要）

1. **导演模型，不抠每一帧。** 先写这场戏在做什么，再写成可见事实。
2. **一镜一个主动作。** 其余人继续闲动作，不要全体定格。
3. **直写镜头能拍到的。** 成语、比喻改成情绪白话 + 一个身体锚点。
4. **切镜要付锁定行。** 每镜重申光、身份、站位；模型跨切不记上下文。
5. **按镜头顺序，不按秒数堆时间码。** 精确秒数对模型不稳定。
6. **禁空词。** 「电影感 / 高级感 / 氛围感」拆成景别、运镜、光源、材质。

## 工作台入口

视频生成页 → **导演配方**：镜头架设、运镜路径、节奏踩点、分镜切法、场景铺陈、动作调度、风格锁定。填写场景意图后可替换或追加到 `videoPrompt`；任务参数保存 `directingRecipe` 来源快照。

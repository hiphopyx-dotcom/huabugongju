# 剧爆棚：静态分镜、Grok 会员与项目参考库（2026-10-28）

## 定义及边界
- **分镜** = 静态画面，一镜一张照片。分镜工作台编辑单帧描述、景别、机位/取景、构图、风格、布光、人物情绪、参考图，不编辑对白、字幕、声音、时码、视频运镜。
- 剧本原文、对白、字幕、原镜长等历史数据**不会删除或改写**。它们仍供剧本拆镜、时间线与视频模块使用；只是静态图片提示词不会再带入这些字段。
- 旧分镜结果仍显示原图，新生成结果通过“上传本镜静态成图”导入并绑定，旧结果不会被删除。
- **参考库** = 当前项目 `assets[]` 中 `library: 'reference'` 的独立分类，用 `referenceRole` 区分角色、场景、道具。每张参考原图只保存一次，分镜通过资产 ID 引用。
- 在分镜页内一次可上传 1—6 张 PNG/JPEG/WebP 参考图，单张最大 12MB；这些图立即绑定镜头，并显示于「资产中心 → 参考库」。导出项目 JSON 备份时，文件数据和分类元信息一起导出，旧版验证器仍能导入；每个登录账户和项目的数据由现有作用域隔离。
- 已生成的本镜图上传为普通**分镜资产**，不会混进参考库。

## 会员接入
- 不修改现有 Grok 会员账户分配表、手机号账户、Mac 文字工作端或视频会员交接。`module-open?module=storyboard` / `module-open?module=image` 按服务端已有映射打开；**不自动切换 Grok 登录账号**。
- 本镜「使用已分配 Grok 会员制作静态图」是安全的人工交接：复制静态图片提示词、下载当前参考图、前往已分配的会员工坊生成，生成后回到镜头上传结果。**没有假冒会员 API，也不声称已经实现会员端自动提交/自动回传**。
- 独立「图片生成」页面的自动出图仍使用配置的 **xAI API（独立计费）**，不是 Grok 会员。现增加明确提示，防止误扣费。若要彻底切换为会员自动生成，需要已有工作端提供明确的、可授权的生成与回传能力，并做实际账号验证；不能用现有账号标签假定自动登录权限。

## 验收
1. 按已分配 Grok 的手机号登录，选择项目→分镜管理→单镜上传角色/场景参考图。
2. 检查资产中心「参考库」仅显示该项目参考素材，普通「全部资产」不混入参考图，另一个项目看不到这批图。
3. 用会员入口制作单张静态图，导回本镜；检查分镜图、资产结果与参考库清楚分离。
4. 导出项目完整备份并重新导入：原图、项目归属、引用、对白/原稿元数据、旧图仍在。
5. 验证脚本、视频、Mac 会员映射及管理员锁定流程不受影响。正式网站发布前再做登录状态与真实界面验收。

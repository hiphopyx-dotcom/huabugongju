# 视频模板提示词

视频生成页新增独立模板区，内置企业宣传、产品发布、电商广告、服务介绍、客户案例、活动推广六类原创提示词结构。

输入保存在当前项目 settings.videoTemplate*；预览只读，随品牌、主题、受众、卖点、CTA、风格、总时长、画幅和所选图片刷新。选择模板只切换预览。用户明确点击替换或追加时更新 videoPrompt，并记录 videoTemplateApplied 作为来源快照；修改可撤销。生成任务保存该来源与最终手工编辑后的提示词。已启用逐镜编排时，其时码、参考图和镜头语言优先。

这是提示词库接入，不安装或调用第三方 Agent 工具包，也不新增视频生成、配音或服务端渲染能力。此前研究的 video-shotcraft、ecommerce-video-skills 等项目提供了产品定位参考，本次没有复制其代码、素材或技能内容。video-talkcraft 的非商业许可证组件未引入。

校验：tests/video-templates.test.mjs 覆盖六类模板、时码完整覆盖、旧工程与不同长度；tests/ui.test.mjs 覆盖独立区域、追加、替换、撤销及任务来源快照。

# 虚拟片场 / 运镜设计

用户已确认第一版范围：视频页独立入口及逐镜入口，布置基础人物与道具，摄影机关键帧、双视图预演，保存参数，导出白模视频与首尾帧。视频参考来自用户上传的CineMap演示，本功能为独立实现，不嵌入其服务。

## 实现

- virtual-stage-core.mjs：纯数据、边界校验、时间插值、轨迹预设、时长等比缩放和任务描述。
- virtual-stage-render.mjs：软件3D透视投影、多边形近裁剪、深度排序与光照明暗，Canvas绘制；不依赖WebGL，兼容已有云浏览器。俯视编辑和平视取景使用同一个三维场景与摄影机。
- virtual-stage.mjs：独立模态编辑器，操作局部草稿，点击保存才更新片场。物体拖动与数字面板、最多40个摄影机关键帧、推进/环绕/穿越预设、播放暂停、时间轴、PNG首尾帧、JSON和WebM导出。
- app.mjs：项目settings.virtualStage和videoShots[].virtualStage分别保存，生成任务包含不可变快照；任务目标时长改变时按比例缩放轨迹，不覆盖原设置。
- storyboard.mjs：逐镜摄像机轨迹、首尾帧与语言进入同一请求。

## 导出

白模视频使用同一绘制函数，优先WebCodecs逐帧编码24fps WebM；不支持时回退MediaRecorder实时录制（帧率受浏览器前台绘制限制），并下载、加入项目素材库。中止、关闭或切到后台时不交付残片，停止媒体轨道。输出原生横竖画幅。首尾帧存为真实PNG资产，绑定全局或对应视频镜头。

## 边界

基础几何人物与道具，不是照片重建或写实结果。人物支持走位、转身关键帧和基础程序步态，摄影机可动画；尚无精细角色骨骼动作导入、网格导入、真实景深、硬件摇轮接入、AI场景生成或AI视频服务。遮挡采用画家排序而非GPU逐像素深度，交叉几何和穿墙时可能出现可见排序误差。真实模型能否服从轨迹取决于将来的参考视频或相机控制适配。

## 验证

核心测试覆盖端点/插值、时长缩放、坐标/焦距/时码校验、轨迹预设与序列化。UI任务测试覆盖原始片场保持不变、任务快照缩放、提示词传递。发布后以浏览器验证布景修改、关键帧预演、首尾帧、WebM输出及保存刷新。

逐帧封装使用MIT许可的webm-muxer 5.1.4（源码已被上游标为由Mediabunny接替；这里只固定其纯封装模块，随附许可证），无运行时网络依赖。

## 人物动作与拖动编辑

人物可一键生成直线行走或原地转身路线，编辑逐时刻位置、朝向，插入/删除中间动作关键帧；首尾动作关键帧保留，随目标视频时长同比缩放。步态为基础几何程序动画，无碰撞检测和自动避障。

俯视图的拖动目标可切换人物/道具、摄影机机位、注视点。人物启用动作后，拖动记录当前时间的动作关键帧；摄影机拖动修改当前选中的摄影机关键帧。人物动作和机位使用独立轨道、同一时间轴。软件3D绘制、首尾帧和逐帧导出都从同一个sceneAt取样，避免导出丢失动作。任务快照携带motionKeys和中文动作路线。

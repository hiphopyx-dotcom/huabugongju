# 剧爆棚：四步流程简化（2026-10-28）

## 唯一主流程
1. **剧本生成**：完成剧本，可修改、保存、导出。原稿不因后续生图被覆盖。
2. **图片生成**：也可直接导入已有 TXT、DOCX、MD 剧本，并沿用当前「拆分镜头/素材拆解」功能，从剧本提取人物、场景、道具设定；制作每个对象的基础参考图，不显示视频运镜、焦距、色调。页面默认角色基础图，原有独立 API 生图和图库折到明确标示的高级区域，不把 xAI API 误称为 Grok 会员。
3. **分镜融合**：以剧本拆出的镜头描述为依据，按镜头从本项目基础图里挑选人物、场景、道具；通过 Grok 会员工坊融合成一张单帧画面并回传/上传为镜头结果。人物原图、场景原图、道具原图仍保持独立，不能替代融合后分镜结果。
4. **视频生成**：只让相邻两张已完成的分镜图成为视频首尾帧；每个相邻分镜对分别准备镜头视频。运镜、色调、焦距、光圈、光影、机位、画幅、目标秒数以及白模参数集中在视频页，进入现有 Grok 会员工作台进行生成，生成的视频再进入剪辑时间线。

## 优先复用已经成功的分镜模型
- 第3步不重新开发、替换或关闭已经配置好的 `storyboard` 模型。用户点击「使用已有分镜模型生成」时，保留 `module-open?module=storyboard` 的原路由；服务端仍按原 `studio_grok_modules` 和当前账户映射选址。此路径的登录、生成执行由原模型承担。
- 原站内分镜工作台 `image-workbench` 的 `storyboard` 分类已恢复，只从第3步展开；保留其原始生成预备、分镜正反打、历史版本、个人图库和 `onUse → shot.assetId` 回写路径，避免重复造轮子。站内自动生成仍走原有图片服务/计额机制，只有人工确认时才提交，不能冒充 Grok 网页会员额度。
- 外部 `storyboard` 工坊的结果回传必须沿用原工坊已提供的能力；此版本不凭空增加新跨域 API。模型原生图库的选用会自动绑定已有分镜；未支持跨域回传的外部结果才需要用户导入。

## 分镜文字字段与视频任务（2026-10-28 修正）
- **第3步分镜只负责生成静态图片**：不提供“画面与动作、台词/声音、字幕、对应剧本原文”四个编辑栏目。原有分镜模型、参考素材选择、图片上传、单帧预览及图库选用仍保留。
- **四个字段统一在第4步视频生成编辑**：按剧本镜头编号选择编辑。“画面与动作”另存 `videoAction`；原静态图的 `description` 只作为旧项目视频动作显示的初始值，修改视频动作时不改静态分镜构图与图片提示词。台词、字幕、对应剧本原文沿用既有 `shot.dialogue / subtitle / sourceText`，不删除原值，也不改写剧本正文 `project.script`。
- **真实进入任务**：选两张相邻的静态分镜作为视频首尾帧时，生成任务携带两镜的动作、台词、字幕、原文作为 `params.videoStory` 和视频提示词；高级多镜头编排也携带各自的四项数据。原文用于理解剧情，不应该作为画面文字绘制。
- **图片任务与视频任务分离**：静态 `shotData` 不再附加原文 `sourceText/sourceLines` 作为生图请求参数；剧本和项目镜头对象仍保留所有旧数据，CSV/完整备份不丢失。

## 兼容和保留
- 原始剧本、台词、字幕、原文、分镜时码以及所有已有素材的 ID、文件数据和锁定状态全部保留；只改入口、页面显示和各阶段交接方式。
- 现有数据库项目结构不升级，不需要删除数据或迁移；项目导出仍是自包含的 JSON，参考库随同项目导出。
- 左侧一级入口仅显示项目和四步骤；节点画布、原稿详细编辑、资产、剪辑、任务队列集中到「高级功能」，仍可访问。
- 已匹配 Grok 会员账户和会员工坊路由不改变。账号匹配 ≠ 自动登录 ≠ 免费 API 调用。本站可以准备会员工坊的提示词、首尾帧和参考图，但第三方会员网页自动生成/结果回传是否具备真实权限，须进一步单独验证；本次未启动付费调用。
- 禁止自动把整剧所有镜头发送到任何付费模型。制作分镜和视频必须显式人工选定并确认，不虚报进度。

## 待人工验收
- 导入完整现成剧本后，图片页能继续整理人物、场景、道具，不突然跳进视频/静态分镜；原剧本不变。
- 生成/上传基础图并选用到本项目，从分镜融合中选择同项目多张基础图，不跨项目、不复制图片 bytes、不破坏锁定资产。
- 生成至少三张分镜静态画面，在视频模块分别从 1→2、2→3 构建独立首尾帧任务；未完成的镜头不能成为视频任务。
- 核对视频色调、焦距、光圈、运镜等进入最终任务提示词，且没有出现在基础图/静态分镜照片提示词里。
- 带完整原图备份/导入项目，核对参考库、Grok 账户绑定和管理员锁定权限。

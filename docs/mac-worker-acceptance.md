# Mac 会员出图端手工验收

CI 跑不了真实的 grok.com 页面。合并前在出图用的那台 Mac 上按下面核对。代码测试绿，不等于网页选择器仍然对得上。

准备：本机已安装 Google Chrome 和 Node 24。不要设置 `JBP_IMAGE_EXECUTION=direct`。不要把连接文件或 token 贴到聊天或日志里。

## 更新

1. 在仓库里切到这条分支，进入 `tools/grok-member-worker`，执行 `npm ci`（已装过 playwright-core 可跳过）。
2. 还在用旧的单账号配置时，不必改 `config.json`。直接双击 `Start.command`，或重新执行 `install-launch-agent.sh`。
3. 要接另一个 `https://…` 站点时，在本机 `config.json` 增加 `extraOrigins`，值必须和连接文件里的 `origin` 一模一样。通配符和 `http` 会被拒绝，进程起不来。
4. 两个及以上 Grok 账号时，改成 `accounts` 数组。每个账号一份连接文件、一个 Chrome profile，并先在那个 profile 里手工登录 grok.com。标签用「甲」这种短名，不要用邮箱。
5. 启动用 `Start.command`，或 `bash install-launch-agent.sh`。多账号会装成 `com.jubaopeng.grok-member-worker.1`、`.2`。某个账号停了，用 `launchctl kickstart -k gui/$(id -u)/<那个标签>` 只拉起它。

## 核对

- [ ] 不改配置时，原来的单账号还能领一张普通出图，图片回到提交人的工作台。存档仍在 `~/Pictures/剧爆棚出图/会员出图/`，没有多出来的账号文件夹。
- [ ] 带标签的账号，原图在 `~/Pictures/剧爆棚出图/会员出图/<标签>/`。工作台这张图上能看到「出图账号 <标签>」和「工作端 primary」。不带标签的完成请求不会多出这两个字段。
- [ ] 两个账号同时开着。关掉或暂停其中一个（见下），另一个仍会领自己的任务。
- [ ] 同一账号不能开第二个进程（提示已在运行）。两个账号的 profile 不要指到同一个目录。
- [ ] 带 1 张参考图的出图：页面上能看到图被加进输入区，生成结果回到工作台。不要出现工作端去读 cookie、或自己请求未公开接口。
- [ ] 参考图张数超过页面当时允许的张数：这一张失败，工作台写「参考图数量超过网页当前允许的张数…」，没有把多出来的图硬传上去，也没有自动再领同一张。
- [ ] 改图：工作台用「以此图改图」提交后，Mac 把原图上传到 grok.com 的图片模式，按修改要求出一张新图。原图还在。
- [ ] 若队列里放进 `type: video` 的任务：工作端不打开生成页面，工作台显示「暂不支持视频任务，未开始生成」。
- [ ] 登录过期：任务失败，工作台写「未登录或登录已过期…」。该账号停止领新任务。重新登录并再次启动后才恢复。另一个账号不受影响。
- [ ] 出现人机验证：任务失败，工作台写「要求人机验证…」。不要代点验证码。该账号停住。
- [ ] 额度用完：工作台写「额度已用完…」，该账号停住，不连续再领。
- [ ] 提示词被拒：只这一张失败，句子是「被 Grok 拒绝生成…」。下一张不同的出图仍可领。
- [ ] 故意把页面语言或按钮改到对不上（或在网页改版后）：工作台出现「网页结构变化：」加上卡住的那一步（例如「上传参考图」或「改图」）。进程不再对这一张重复点击。若提交已经点出去、结果对不上，状态是待核对（uncertain），刷新工作台也不会再次领到它。

## 看日志时

日志里可以有账号标签和任务编号。不应出现 `workerToken`、lease 全文或 cookie。

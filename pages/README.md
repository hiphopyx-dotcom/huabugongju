# 剧爆棚 GitHub Pages 版

纯静态页面，直接部署本目录，不需要运行 Node 服务。
本地项目、资产、分镜、画布、剪辑、字幕、浏览器 WebM 导出均保留。
Grok 生成使用网页会员账号交接，不读登录 Cookie、不存账号密码、不冒充官方API。
上传素材和剧本保留在浏览器，不会自动提交到 GitHub。


## 将剧爆棚剧本带到个人 ChatGPT 网页聊天（2026-10-24 预览）

剧本页新增 **「转到我的 ChatGPT 写剧本」** 按钮，沿用原有 Grok 的“站内准备材料、外部账号实际创作、手动导入结果”思路，但目标明确是用户已登录的 `https://chatgpt.com/`。

操作：选择续写下一集 / 精修当前剧本 / 质量诊断 / 大纲人物小传 → 选择一集或全文 → 补充本次要求 → 预览交接包 → 点击「复制并打开 ChatGPT」→ 在 ChatGPT 网页输入框粘贴并自主发送 → 复制 ChatGPT 生成的正文 → 返回同一项目点「带回生成结果」→ 粘贴并保存候选稿 → 审稿无误后人工采纳。

安全及边界：

- **这是 ChatGPT 网页账号交接，不是 OpenAI API 接口。** 不需要配置 `OPENAI_API_KEY`，不读取浏览器的 ChatGPT Cookie、聊天记录，也没有权限自动发送新消息或抓取回复。ChatGPT Plus/Pro 用户可按照自己的聊天账户能力使用，实际以对应网页会话权限为准。
- 不将任何剧本文本放进网址、第三方链接、外部 API 查询参数。跳转目标只能是 ChatGPT 官方站首页或明确填写的现有 `/c/<聊天ID>` 页面；跨域及附带查询参数的链接会被拒绝，避免隐私泄露。若浏览器没有共享 ChatGPT 网页登录状态，用户需要在打开的新页面自行登录。
- 剧爆棚只复制包括作品名称、题材、创作约束、角色/场景/道具**文字设定**和明确选择的分集正文在内的交接包，不自动上传图片、视频或真实素材的二进制内容。
- 为防止整部80集剧本一次丢给浏览器导致截断：按集精修时仅附本集；下一集续写时参考所选集及前一集，并对极长上下文提示截取范围；超过安全上限的全文会报错并要求分集交接，**不会偷偷删掉剧本后半段**。
- 回传结果先存入 `chatgptCandidates` 候选记录，正式剧本仍保持不变。可人工确认将续写的一集追加到末尾，或只替换选中的当前集。采纳前会核对当初的整部剧本内容是否已被改动，若有人后来手动编辑便拒绝覆盖。质量诊断、大纲小传不能通过此入口直接覆盖原剧本。
- 交接历史在当前本地项目 `chatgptHandoffs` 中保留最近8项，候选稿最多留12项。数据由现有项目备份/保存流程处理。此功能不使用服务端数据库迁移、不产生额外 API 费用。
- 旧的 Grok 任务、云端账号、资产生成及双模型 API 评审实验保持不变，互不影响。

在预览环境需确认：macOS/Windows 与移动浏览器的剪贴板权限、ChatGPT 网页是否已登录、弹窗拦截、现有聊天链接、剧本工作台返回时的候选导入、40/80集版本隔离及用户人工采纳前的原稿完整性校验。自动化用模拟页面测试，不等于已经操作用户个人 ChatGPT 账号。

# 剧爆棚 GitHub Pages 版

纯静态页面，直接部署本目录，不需要运行 Node 服务。
本地项目、资产、分镜、画布、剪辑、字幕、浏览器 WebM 导出均保留。
Grok 生成使用网页会员账号交接，不读登录 Cookie、不存账号密码、不冒充官方API。
上传素材和剧本保留在浏览器，不会自动提交到 GitHub。


## 全局分区折叠（待合并测试分支）

适用：项目空间、剧本、素材、画布属性、分镜卡片、视频生成与多镜头设置、剪辑时间线、任务列表、云空间、模型中心、嵌入图片工坊、账户/管理员弹窗，以及虚拟片场的场景与操作区。

- 每个功能区顶部显示 **▾ 收起 / ▸ 展开**。大型页面上方提供 **全部展开、全部收起、恢复默认**。
- 折叠设置按“当前项目 + 页面 + 功能区”记录在当前浏览器的 `localStorage`，切换页面及重新打开时会恢复。此设置不包含个人剧本、素材内容，也不会上传到云端。
- 分镜卡片逐条折叠；视频多镜头设置、素材网格及时间线片段可单独折叠。部分较长页面首次默认展开前两组，其余收起，避免一次看到过量选项。
- **只是改变界面可见性**：不删除表单、不改剧本、不停止或重试生成任务、不修改模型余额、不覆盖视频素材。页面切换按原有行为保存项目内容。
- 外部网站的 iframe 仅可作为整体嵌入区折叠；其内部 UI 由外部服务控制，不能从本站强制更改。
- 本功能不依赖任何 AI 模型或付费 API。跨设备界面折叠状态不自动同步，但各设备项目数据保持现有机制。

上线前应手动检查：剧本正文输入→收起→重新展开，分镜编辑后折叠与展开，视频参数与上传，时间线拖拽、云保存，管理员弹窗操作、虚拟片场拖动，以及移动端较窄窗口的操作按钮是否可点。

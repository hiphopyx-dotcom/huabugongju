# 剧爆棚账户服务

## 剧本导入与拆镜

首页、“导入剧本 / 拆镜”和分镜页提供直接入口，两种模式均可用。支持粘贴、TXT（UTF8 / UTF16 / GBK）、MD、DOCX 正文；不读取旧版二进制 DOC 或扫描 PDF。20MB 文件、30万字正文上限，DOCX 正文解压上限6MB，不加载文档中的外部资源。导入先预览再替换剧本文字，保留原分镜和素材。

本地拆分按分集、场次、动作、台词生成原文对应镜头。AI 拆镜复用 `/api/generation`，每场按4000字/35行分批，每次明确提交一批；管理员必须选择已连接的执行账号，成员不能指定后台账号，仍由服务端使用成员分配。提交标识先保存，网络不确定时按原标识查询/重试。关闭窗口、刷新后可查原任务，不自动重复调用。模型需要返回完整结构、有效原文行号与逐字台词；漏行、跨场、乱序或格式错误会保留原结果并阻止写入。模型画面描述仍需人工核对。

结果核对后才可追加/替换，核对期间剧本、镜头或账号变更会阻止过期写入；批次完成状态跟随项目保存。人物、场景、道具仅匹配本项目同名同类型图片。镜长、镜头语言、连续性和对应原文进入现有分镜编辑及任务输入。此流程不自动生成图片/视频，也不改动独立 Grok.me 工坊。

验收：自动检查含文档解码、压缩DOCX、分场、行号覆盖、账号切换、提交幂等、过期预览、重复应用；浏览器验证DOCX导入、本地拆分、保存刷新及模拟AI选择账号/回填。真实模型质量和耗时需经授权后单独运行，模拟验收不作为真实生成证据。

Vercel 项目 Root Directory 为 deploy，启用 sourceFilesOutsideRootDirectory。构建时复制 ../pages 到 public；Node 24 Functions 提供 /api/accounts。

## 初始化

数据库执行 schema.sql 中的语句。服务端环境变量 DATABASE_URL 为 Neon 数据库连接，STUDIO_SETUP_TOKEN 为随机32字节初始化密钥；两者不写入仓库。首次初始化页面只允许持有初始化密钥的管理者设置姓名、手机号和密码。初始化后不能再次创建管理员。

## 权限

手机号为管理员分配的登录名，无公开注册，不发送短信验证码，不表示手机号已验证。密码使用独立随机盐的 scrypt 哈希。登录会话为 Secure/HttpOnly/SameSite=Strict Cookie，数据库只保存会话摘要。用户不能提升管理员角色，账户停用、改绑、重置密码后旧会话失效。

管理员可添加 Grok 账户标识，创建用户并分配对应标识，不保存 Grok 密码或 Cookie。只有通过后端管理员验证的 grok-open 入口会跳转到 Grok。分配记录不代表自动登录 Grok 或调用网页会员额度。

模型中心可配置剧本、白膜、图片、分镜页面，在框架限制允许时嵌入；被原站禁止嵌入时独立打开。输入包是本站定义的 JSON，旧模型需适配协议才能自动读取；当前不声称已经打通原模型的 API。

本地素材按登录账号分库存储。不能把 IndexedDB 隔离当作服务端保密边界；同一设备应使用独立系统账户。GitHub Pages 不托管账户服务，正式账户版使用 Vercel 同源站点。

成员新建与重置密码统一为6–8个字符，不要求特定字符组合。登录仍接受已有长密码，编辑留空保留原密码。重复手机号返回409并引导编辑原账户；创建错误在当前表单显示，不跳到页面底部。

登录等待身份验证及个人项目库切换完成后关闭窗口；切换失败在原登录窗显示错误。个人库连接先打开成功再替换旧连接，切换串行执行。项目读取失败回滚到原库和原工程，允许重试；初始化加载与身份切换按顺序执行，不删除旧项目或清理浏览器存储。

管理员账户池支持每次1–50个账户标识批量登记，重复标识跳过；可改名、停用和重新启用。已有成员可直接改绑或解除匹配，无需修改密码；改绑撤销该成员旧会话。停用 Grok 标识保留对应关系，但不再参与模型入口解析，也不能分配给新成员。此功能不保存 Grok 密码，不代表已登录或接通生成服务。

文字任务通道：部署前执行 generation-schema.sql（仅新增工作端、任务表及索引）。管理员在账户池下载每账户的Mac连接配置；成员用顶部“文字生成”提交任务。Mac运行V3工具导入配置并启动工作端，主动领取并回传文字，Grok凭据不上传。连接配置原文只下载一次，服务器保存哈希，重新下载会轮换；撤销可立即阻止后续领取。仅提交人能查看任务结果。成员登录响应不再返回底层Grok名称或邮箱。详见 docs/integrations/mac-text-bridge.md。

## 账号资产总览

上线前执行 `asset-schema.sql`（仅新增资产索引表及索引）。管理员入口提供“账号资产总览”，也可在成员行点“查看该账号资产”。支持账号、图片/视频/音频/文字类型、关键词筛选，24条分页及详情。`/api/assets` 校验当前服务端会话及管理员权限，成员无法读取其他账号的记录，记录归属取自会话且检查上报时的账号标识，避免切换账号时串库。

文字任务直接读取已有服务器任务及结果。已登录账号的本地工程在登录及成功保存后后台同步素材目录与缩略图；上传内容不包括本地视频、音频原件，不能据此跨设备播放本地完整视频。生成结果绑定素材标记为“用户绑定的任务结果”，普通素材标记为“本地素材（生成来源未验证）”，不会把导入文件伪称AI生成。保存成功不依赖资产同步成功，后续保存会重试。已有工程需在原设备登录其所属账号，目录才会上报；访客工程不归入登录账号。

独立 `grok.me` 图片工坊目前没有向本站回传资产目录的接口，不能通过GitHub/Vercel更新该工坊。尚未回传的历史资产不会自动出现在总览；列表明确显示此覆盖范围，空列表不代表没有生成过。后续若接通原工坊，应由其服务端使用统一身份回传真实资产，不按当前Grok分配或客户端任意owner字段推断归属。

## 管理员资产锁定与回收站

已有数据库上线前执行 `asset-controls-migration.sql`（仅增加管理状态字段）。在账号资产总览的详情中锁定、解锁或移入回收站，在“范围→回收站”恢复。锁定允许查看和使用，冻结本站目录更新、正常工程编辑和删除；仅管理员可解锁，锁定状态禁止直接回收。文字任务结束后才能管理。管理操作记录操作者与目标，版本检查拒绝过期操作。回收保留内容供恢复。

成员工程在登录、保存、重新获得焦点、恢复网络及每15秒检查当前项目的状态；缓存状态在离线期间继续限制正常编辑。删除清理引用并暂存本地媒体供恢复；恢复不覆盖随后修改的分镜引用。回收的文字结果不再从成员接口返回。独立工坊未接入资产、已下载文件、工程副本和直接操纵浏览器存储不在强制控制范围，不能当作媒体DRM或远程擦除。

## 估算 token 额度

先在数据库执行 `migrations/estimated-token-quota.sql`（增量建表与原子函数），再发布应用。已有账号默认不限额；管理员在“额度与用量”设置累计总额度，0 会阻止新提交。已用和预占之和是总额度下限。

文字近似按 ASCII 字节/4、其他 UTF-8 字节/3 计量；提交时预占输入与最多64KB输出的上界21,846，完成后按实际输入输出退差额。失败、过期的任务释放预占；历史无预占的任务不追溯扣费。提交建单与预占在同一数据库事务内，账户行锁防止并发透支，终态不可重复扣款。

图片默认2,000/张、视频1,000/秒，均为可修改的站内估算系数，并非供应商真实 token 或货币价格。保存本地请求不扣额；“提交管理员生成”预占，管理员核对实际生成结果后结算，失败/取消释放。上传现有素材、绑定结果、本地白模预演不扣费。独立第三方页面的操作无法由本站计量。每个手机号独立记账，成员无权改变系数、总额度、他人的账本或媒体结算状态。调整系数不改变旧请求。

验证：`node --test deploy/tests/quota.test.mjs`；`tests/quota-postgres.sql` 可在 PostgreSQL 中运行，校验预占、幂等、结算、额度下限及建单失败回滚；测试数据在同一语句内回滚。
